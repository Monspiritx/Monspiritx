## 🚀 Projects / プロジェクト
 
### 🔍 [Annotator Fraud Detection](https://github.com/Monspiritx) *(Internship @ BOTNOI · AnnotateAI platform)*
**End-to-end unsupervised fraud detection on annotation platform behavior data**
- **Data:** Raw event logs + aggregated behavioral features (6 users, 1,863 events)
- **Features:** 12 event-derived features — `same_ts_pct`, `tasks_no_play_rate`, `replay_ratio_from_log` etc.
- **Models:** Rule-based scoring · Autoencoder (PyTorch) · DBSCAN · LOF · Isolation Forest
- **Result:** callmewinner2602 flagged by all 4 ML methods — highest confidence fraud signal
- **Stack:** Python · PyTorch · scikit-learn · pandas · Jupyter
